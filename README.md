# 坦克大战 (Tank Battle)

一个用纯 HTML + Canvas + JavaScript 实现的经典坦克大战游戏，单文件即可运行，无需任何依赖。

## 玩法

- 控制你的坦克，**守住右下角的基地**，消灭所有敌方坦克。
- 基地被摧毁或生命归零则游戏结束。
- 每消灭一关的全部敌人进入下一关，敌人会越来越强。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 射击 | 空格 / J |
| 暂停 | P |
| 静音 | M |
| 开始 / 重新开始 | Enter |

手机触屏设备会显示虚拟方向键和射击按钮。

## 道具

| 图标 | 效果 |
| --- | --- |
| ⭐ 星星 | 升级火力（更快、更强的子弹，满级可打碎钢墙） |
| ♥ / + | 增加一条生命 |
| ◉ 护盾 | 短暂无敌 |

## 运行

直接用浏览器打开 `index.html` 即可，或使用任意静态服务器：

```bash
npx serve .
# 或
python -m http.server 8000
```
