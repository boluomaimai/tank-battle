# 坦克大战 (Tank Battle)

一个用纯 HTML + Canvas + JavaScript 实现的经典坦克大战游戏，单文件即可运行，无需任何依赖。

> 在线试玩：https://boluomaimai.github.io/tank-battle/

## 游戏目标

控制你的坦克，**守住右下角的基地**（旗帜标志），消灭每一关的所有敌方坦克。

- 基地被敌人击中，或生命归零，游戏结束。
- 每通关一次进入下一关，敌人数量与强度都会提升。

## 地图元素

| 元素 | 说明 |
| --- | --- |
| 砖墙（橙色） | 可被子弹击碎 |
| 钢墙（灰色） | 普通子弹打不碎，满级火力可击碎 |
| 基地（旗帜） | 必须守住，被击中即游戏结束 |

## 道具说明

游戏中会随机掉落道具，开坦克压上去即可拾取，屏幕上方会弹出提示。

| 图标 | 颜色 | 名称 | 效果 |
| --- | --- | --- | --- |
| ★ | 黄色 | 火力升级 | 移动更快、射击更快；升到满级后子弹可击碎钢墙 |
| ♥ | 绿色 | 生命 +1 | 增加一条生命（最多 5 条） |
| 盾 | **蓝色圆点** | 护盾 | 获得 6 秒无敌，坦克周围出现蓝色光圈 |

> 常见疑问：那个「蓝色圆点」就是**护盾道具**，拾取后坦克周围会出现蓝色光圈，6 秒内免疫任何伤害。

## 运行

直接用浏览器打开 `index.html` 即可，或使用任意静态服务器：

```bash
npx serve .
# 或
python -m http.server 8000
```
